AC: ACTUAL (Arma Commander Actual) - Everon, Arland and Kolguyev
================================================================
An unofficial fan port of the Arma 3 "Arma Commander" mode. Command squads
on the map, take over friendly AI soldiers, buy units with requisition
points (RP), and capture bases. Play solo against AI or share command
with friends. Pick sides and match options before starting.
This is an alpha build, so expect rough edges. There are no victory
conditions or saved matches.

This guide is for the Windows Steam ZIP launchers. For an installed
Workshop copy, enable the mod and choose an AC: Actual scenario in the
game's Scenarios or Host menu; use the in-game setup screen, then Start.
No external launcher is needed for Workshop play.

FIND YOUR WAY
-------------
Start with WHAT YOU NEED and HOW TO START for solo play, or PLAYING TOGETHER
for hosting/joining. THE BATTLEFIELDS explains layouts; CONTROLS and ON THE
COMMAND MAP are the command reference. TIPS and KNOWN LIMITS cover common snags.

BBB DEPENDENCY / ZIP UPGRADE
----------------------------
This paired package contains ArmaCommanderReforger and BetterBattleBuddies.
Keep both folders together. Upgrading from an old single-addon ZIP requires
downloading and extracting the complete ACActual-WithBBB.zip once; its old
updater cannot install BBB. New paired packages update both addons together.

WHAT YOU NEED
-------------
- Arma Reforger on Steam, installed and up to date (Windows PC).
- No Workbench or extra mod is required for vanilla play from this ZIP.
- Optional RHS/UA/ACE mods must already be downloaded. The launcher selects
  their addon IDs but currently expects faction files in
  E:\ArmaReforgerMods\addons (a development-PC path); other installs may need
  addon search paths adjusted. It does not download these mods for you.
- If All-in-One Command Menu is installed locally from Workshop, Play/Host/
  Join load it automatically. Joiners need it too when the host loads it.

HOW TO START
------------
1. Unzip anywhere, e.g. your Desktop. Keep the files together, and don't
   rename the "ArmaCommanderReforger" folder inside.
2. Close Arma Reforger if it's running.
3. Double-click  Play-ACA.cmd  (next to this guide).
   A setup menu opens first (side, AI, RP, threat level...): press Enter
   to start with the remembered settings (option 1 switches the map:
   Arland, Everon or Kolguyev). The game then starts straight into
   the scenario (singleplayer and offline).
   The first load takes a while because the game compiles the mod's scripts.
   If Windows SmartScreen asks, choose "More info" > "Run anyway". It's a
   launcher script that starts the game with the mod loaded.
   The launcher finds the game in any Steam library. If it can't, a window
   asks you to pick ArmaReforgerSteam.exe once (in ...\steamapps\common\
   Arma Reforger\); it remembers the answer. If anything fails, send
   ArmaCommanderReforger\launcher-log.txt to the person who sent you this.

PLAYING TOGETHER (EXPERIMENTAL)
-------------------------------
One person hosts on their PC and plays; the others join. Everyone needs this
same mod version (send them the same zip), optional mod set, faction/ACE
choices and up-to-date Reforger.

HOST (one person):
1. Install the free "Arma Reforger Server" tool once: in Steam, go to
   Library, switch the filter to include Tools, find "Arma Reforger Server",
   click Install.
2. Double-click  Host-ACA.cmd
   - First a HOST SETUP list appears: players' side (any, or everyone on
     US / USSR with the AI commanding the other), starting RP, income,
     which sides get an AI commander, AI skill and reaction speed, soldier and squad
     limits, respawn delay, Game Master for everyone, shared command.
     Type a number to
     change one, Enter to start. Your choices are remembered.
   - The first time, it explains ZeroTier and asks whether to set it up
     (see "Connecting" below).
   - A server window opens (leave it open) and Windows may ask about the
     firewall: tick BOTH Private and Public and click Allow.
   - The script prints your addresses, waits until the mission has loaded
     (about 1 minute), then starts your game and joins automatically.
3. Give your friend the address to join (see "Connecting" below).
4. When done: quit the game, then close the server window.

JOINING (everyone else):
1. Double-click  Join-ACA.cmd
   - The first time, it explains ZeroTier and asks whether to set it up
     (see "Connecting" below). Say Y and paste the network ID the host
     sent you.
   - Then type the host's address: numbers like 10.147.17.5 (the host
     reads it off their Host-ACA window). Next time just press Enter
     to reuse it.

CONNECTING OVER THE INTERNET - pick ONE:
 a) Easiest: ZeroTier, set up by the launcher. ZeroTier is a free app that
    puts your PCs on one small private network, as if you were on the same
    home Wi-Fi. Host-ACA.cmd and Join-ACA.cmd explain exactly what it
    does and ask first; if you say yes they download it from zerotier.com,
    check its signature, install it and join the host's network (Windows
    asks for administrator permission once). No account needed for
    players. The host sends everyone the network ID (16 characters) and
    the ZeroTier address their window shows.
    To disconnect: Leave-ZeroTier.cmd. To remove it: Windows Settings >
    Apps > ZeroTier One > Uninstall.
    Already using another virtual-LAN app (Radmin, Tailscale...)? Say N
    to ZeroTier and use that app's address instead.
 b) Port forwarding: the host forwards UDP port 2001 on their router to
    their PC and gives their public IP (search "what is my ip").
 On the same home network, just use the host's 192.168.x.x address.

WHO DOES WHAT:
- Players join the chosen side, or pick in game when Players' side is any.
  The first eligible player on a side takes command. With Shared command
  on (default, option 13), others can press "Take command" too: every
  commander can order every squad and all share one RP pool. Non-commanders
  can possess friendly AI soldiers (F7), drive, fight and ping.
  "Leave command" gives up command. Shared command off allows one commander
  per side. The AI commander leads a side only while no player commands it.
- These launchers run a dedicated server. Being the first joiner does not
  grant Game Master by default. Configured server admins are trusted;
  option 16 "First player is host" explicitly trusts the first connection
  for this session (no transfer after disconnect). Option 12 gives Game
  Master to everyone. Use these options only for your intended group.

IF IT DOESN'T CONNECT:
- Both players close everything and try the files in the "If joining fails"
  folder instead (Host-ACA-online / Join-ACA-online).
- Check the address, that the server window is still open, and the firewall
  question from step 2.
- Logs: host server log in ArmaCommanderReforger\.local-server\logs, game
  logs in Documents\My Games\ArmaReforger\logs. Send the newest ones.

THE BATTLEFIELDS
----------------
The following describes the hand-built vanilla layouts. Faction choices
replace the sides and forces; smaller or generated layouts move their HQs.

ARLAND: US starts at Airfield with Barracks; USSR starts at Heide with
Arlberg and Arlberg Harbor (hidden from opponents until discovered).
Harbor, Farm, Military Hill, Ridge and Lighthouse start neutral. Both
lighthouses are tactical points with no income or deployment. US starts
with two rifle squads, a weapons team, a crewed truck and a crewed Humvee.

EVERON: US starts at the Airbase in the north; USSR starts at Saint-Pierre
in the south-east. Towns, villages, military sites and industry form the
objectives. Option 15 offers North/South halves and flashpoints around
Saint-Philippe, Montignac or Levie, as well as generated layouts.

KOLGUYEV: always generated from the terrain's named locations. Generated
whole-map, half-map and flashpoint choices are also available on Arland
and Everon. Both sides' HQs and starting forces move to the generated plan.
There are no pre-placed pads in generated games: build a helipad before
buying helicopters. Off-map air lift needs no pad.

The launchers choose settings before launching and skip the in-game setup
screen. When using an included scenario through the game's menu instead,
the in-game setup screen can preview a generated plan, reroll its seed and
move bases (click a base, then its destination). Use "Return to match
setup" to return, then Start. Installing another terrain alone does not
add an AC: Actual scenario; mission makers must set one up.

- Soldiers inside a base's ring capture it; a greater advantage in numbers
  captures faster. Garrison defenders deploy when enemies approach.
- Income is 5 RP plus owned income bases' values every minute, multiplied
  by the host's income setting. Purchases deploy at owned bases that allow
  spawning and are not contested. Prices and stocks depend on host options.
- There is no win screen: the match continues until you end it.

CONTROLS
--------
F9 (or M)   Open or close the command map. No map item is needed.
F7          Take over the soldier you're aiming at. On the map, F7 takes over
            the marker under the cursor.
F8          Go back to your own commander body.
            F7 only takes living AI in your side's commandable squads, never
            another player's soldier or command unit.
            Rebind mod keys in Settings > Controls > AC: Actual.
Y           Game Master (host/admin). This is a debug and "fix Arma" tool:
            unstick vehicles, delete stuck units, spawn stuff. Press Y again
            to return.
`  (backtick, the default command menu key)
            The normal Reforger squad orders. They only work while you're
            controlling a squad leader.

ON THE COMMAND MAP
------------------
- Left-click a squad marker to select it. Left-click empty ground to deselect.
- Several squads: hold Ctrl and drag a box around them (a plain drag still
  pans the map), or Shift+click markers to add/remove. Orders then go to all
  of them; move orders spread them in a line about 40 m apart.
- Waypoints: Shift+right-click adds a waypoint after the current order (up to
  8; with Defend armed, the last stop is a defend). The line shows the chain.
- The blue panel on the right shows the selected squad:
    Combat / Fast / Silent  how the squad moves
    Defend, then right-click   defend that spot
    Get in, then right-click   board a vehicle near the click
    Get out / Unload       dismount the squad, or the passengers it carries
    Ride, then right-click the destination. A free crewed truck nearby
                           (within 800 m, no farther than half the trip)
                           picks up the squad and drives it there. Trips
                           under 400 m, or with slow road detours, are walked.
    Reinforce              missing soldiers cost 3 RP each, sent from the
                           nearest eligible owned base. Refused with enemies
                           within 300 m, even if not spotted. At a deploy
                           base it also heals/restocks soldiers (free if
                           ammo-only); vehicle rearm/repair costs extra.
    Halt                   drop all orders and stand still
    Switch to squad        jump into that squad's leader
    Take over gunner       jump into the gun of the squad's vehicle
- RIGHT-CLICK on the map moves the selected squad there. A line shows each
  squad's current order.
- To toggle Defend or Get in off again, click the same button a second time.
- Garrison, then right-click a building to hold its usable windows/doors.
  Advancing Combat infantry can try a flank when stalled against a fresh contact;
  defending, pinned, Fast and Silent squads are excluded from that behavior.
- BUYING UNITS: click "Requisition" at the top of the panel, click a unit in
  the list, then left-click inside the ring of one of YOUR bases. The unit
  deploys at that spot (a click just outside is pulled to the ring's edge). Right-click cancels. Vehicles come with crews. The list shows
  the price, and your RP is shown in the panel. With default stepped
  pricing, ordinary infantry, cars and trucks have unlimited stock, but
  each purchase makes the next one dearer
  (+15% of the first price each time; +25% at low threat, +8% at high).
  Rare units (helicopters, armour, mortar teams) show how many are left.
  With fixed-stock pricing every unit has a limited stock and fixed price.
  Purchases also stop at the host's living-soldier threshold; a purchase
  begun below that threshold may take the side over it.
- SUPPORTS: click "Supports" in the panel, click one (price and cooldown are
  listed), then RIGHT-CLICK the target on the map. Everyone on your side gets
  a message with the grid and arrival time. Mortar calls and illumination
  need a bought mortar team, stopped and set up in range (M252 about 2.9 km,
  2B14 about 2.3 km; at least 100 m). Available:
    Mortars: HE small / HE large / creeping barrage / smoke screen
    Illumination flares (4 flares over about a minute)
    Artillery: howitzer battery (virtual, no range limit, no team needed)
    Air: rocket strike, bomb run (virtual by default; RHS can show a jet
         flyover, and mission makers can configure delivery)
    Helicopter: rocket run, gunship (90 s), door gunners (120 s).
         With helipads, buy the support helicopter first: it flies from
         its pad, returns and services. Layouts without pads use off-map
         combat support. Helicopters CAN be shot down.
    Helicopter: air lift. Select an infantry squad, then right-click a
         destination at least 400 m away. One or two off-map helicopters
         carry the squad to clear ground within 200 m of the click.
         Capacity depends on the helicopter; troops without seats stay behind.
         The squad must be on foot with no player controlling a member.
         No pad needed; default 40 RP / 4-minute cooldown. The squad holds
         at the landing zone; it cannot take other orders during the lift.
  A red ring with a countdown marks each incoming support on the map.
  Keep your own troops out of it!
- REPORT (panel button, everyone): your side's running after-action report:
  soldiers and vehicles lost, enemy killed, bases won and lost, RP earned and
  spent, and the last big moments (bases taken or lost, squads wiped out,
  vehicles lost). Kills by bombs and the howitzer battery aren't credited.
- FIRE AT WILL (panel button): for a squad with a radio operator, or a
  "Forward observer team" from Requisition (12 RP, these start with it on),
  it calls your mortars on enemies it sees, at least 150 m away and never
  with your own troops within 120 m (the usual RP and cooldown, needs a set-
  up mortar team in range). For a mortar team it fires a couple of rounds
  of its own every 30 s at any spotted enemy in reach, free but scattered.
  Press it again to stop. The AI commander's observers and mortars always
  fire at will.
- PINGS (everyone, not just commanders): Alt+click the map for "Look
  here", or Alt+right-click for a picker (Look / Attack / Defend / Support,
  or press 1-4). Pings show on your side's map and on screen, up to 3 per
  player (Look lasts 15 s, the others 60 s). Alt+click your own ping to
  clear it. A commander can click a Support ping to aim a support at it.
  To ping from the 3D view, bind "Ping" under Controls > AC: Actual (tap:
  look, hold: pick).
- SHARED COMMAND on the map: other commanders' orders are drawn dashed
  with their short name, the panel shows who ordered a squad and warns
  before you override a fresh order, and lists the commanders and RP spent.
- Several markers on top of each other: click again to cycle through them.
- Base rings: blue = yours, red = enemy, yellow = neutral.
- Two small bars under each of your squads: health (green, amber, red) and
  ammo (blue, red when low). The panel shows the numbers, plus low fuel.
- LOGISTICS: ammo trucks, repair trucks, fuel tankers and ambulances top up
  friendly soldiers and vehicles within 25 m while they are stopped. Each
  carries limited stock and restocks only while parked at one of your spawn
  bases. The AI uses them too, so hunting its supply trucks pays off.
- HUNT: with a squad selected, right-click a red enemy marker. The squad
  follows that enemy group wherever your side last saw it, until it is
  destroyed, the trail goes cold, or your squad can no longer fight
  (red order line).
- YOUR EMPTY VEHICLES show as light blue markers while any of your
  soldiers is within 400 m (or they're at one of your bases); otherwise at
  their last known spot for 10 min. Right-click next to one with Get in.
  Vehicle crews always show their vehicle's symbol, "(dismounted)" when
  they're out of it.
- RADIO: sightings by your AI squads and sentries also come in as short
  radio calls in chat (at most one every 15 s).
- INTEL: enemies reported to your side show as red hostile symbols
  (infantry, vehicle, armed vehicle, armour, helicopter) at the spot they
  were last seen. After 30 s they turn dashed ("suspected"), after 90 s
  they disappear. AI perception and players' line of sight within 300 m
  count. Owned bases also automatically report enemies inside the capture
  radius plus 60 m, without line of sight or a physical sentry. The INTEL box at
  the top left lists new sightings, newest first. The enemy AI works from
  the same kind of picture, so staying out of sight matters.

THE ENEMY AI
------------
The AI commander on either side keeps a reserve, comes at
a base from several directions, shells it and lays smoke before assaulting,
has one squad pin you down while the others move, pulls beaten squads back,
counterattacks bases it just lost, and calls mortars on you when you attack
its bases.

TIPS
----
- HELICOPTER / TRUCK INSERTIONS: order a squad to "Get in" your transport.
  Then (squad or transport selected) click "Unload at LZ" and right-click the
  landing zone: they jump out by themselves as soon as the vehicle is down
  and slow near it: skids within about 3 m of the ground, a rooftop or the
  water, which covers a low helocast.
  Flying or driving yourself? F6 drops every passenger squad right now; if
  you are still high or fast it warns you first, and F6 again drops them
  anyway (they may get hurt from high up).
- Load a squad into Truck 1: select the squad, click "Get in", then right-click
  on the truck. Then move the TRUCK's crew, and the passengers ride along.
- GUNNER DRIVES: sitting in a vehicle's gun (e.g. a Humvee M2) with an AI
  driver, use W/S to drive forward/back and A/D to steer, and shoot at the
  same time. Give the squad a map order and the AI driver takes over again.
  Typical flow: buy an armed Humvee, order it near the fight, press F7 on its
  gunner, then drive it yourself.
- You can fight in person too. Press F7 on any of your soldiers, then F8 to go
  back to your commander.
- Stuck AI or a flipped vehicle? A host/admin with Game Master can use Y
  to fix it. See the dedicated-server permissions above.
- If your commander body dies you respawn at your HQ (or nearest base you
  own) after 15 s. If it dies while you are controlling another soldier, you
  keep playing that soldier and a new commander body is waiting at base (F8).

OTHER FACTION MODS (NO PROMISES)
--------------------------------
AC: Actual can play any two eligible factions a map lists. Our three worlds list
the game's US, USSR and FIA, plus RHS US / RHS Russia when RHS is loaded,
and UA through Ukraine Armed Forces RHS. Another faction mod only works if
the map lists it and the mod sets up its factions the standard way (Game
Master catalogs). Even then it may look rough (mixed uniforms, a squad
leader as your command unit, vanilla stand-ins). Only RHS and UA are
hand-fitted. Want a faction mod supported properly? Ask on GitHub:
  https://github.com/propst-design/ACActual/issues

KNOWN LIMITS (alpha)
--------------------
- Off-map air lift has passed automated transport and terrain-clearance tests;
  broader multiplayer acceptance remains open.
- Multiplayer has had friend playtests, but coverage is limited, especially
  for joining during setup and generated layouts.
  Expect bugs; logs and a short note of what happened are gold.
- No victory condition or save/resume system.
- Controller/console play is unverified; these launchers require Windows.
- AI base building is not implemented. Construction trucks can build forward
  deploy points, but command posts do not yet store building supplies; keep
  a stocked construction truck available for further construction.
- Game logs are in Documents\My Games\ArmaReforger\logs if something breaks.
  Sending the newest console.log helps a lot.
- Found a bug? Report it at https://github.com/propst-design/ACActual/issues
  (what happened, version, host or client, and the newest log folder zipped).
  The project page lists what most needs multiplayer testing.
